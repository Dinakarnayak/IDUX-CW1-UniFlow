# UniFlow — Functional Mobile Prototype

This branch contains the functional mobile implementation of the UniFlow ID&UX concept.

## Run
Open `mobile-app.html` in a browser. No build tools or dependencies are required.

## Functional interactions
- onboarding → university sign-in → personalisation → dashboard
- task completion and task creation
- calendar conflict review and schedule update
- study-plan generation and acceptance
- focus timer with pause/end states
- wellbeing check-in
- group message interaction
- progress/analytics view
- what-if workload simulation
- accessibility and notification controls
- privacy controls and local data export
- localStorage persistence for user task state

## UX implementation
The interface uses a restrained professional visual system intended to resemble a real university productivity product rather than a promotional student concept. The prototype is intentionally self-contained: there is no real university authentication, cloud database, external AI service, or calendar provider.

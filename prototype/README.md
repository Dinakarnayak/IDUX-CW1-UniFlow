# UniFlow — Advanced+ ID&UX CW1 Prototype

This branch contains a professional expanded prototype for the CO4223/CO7223 ID&UX Coursework 1 concept.

## 15-screen interaction set
1. Onboarding
2. University sign-in
3. Personalisation
4. AI dashboard
5. Smart calendar
6. Task & deadline manager
7. AI study-plan generator
8. Generated study plan
9. Focus mode
10. Wellbeing check-in
11. Group collaboration
12. Progress & analytics
13. What-if simulator
14. Settings & accessibility
15. Privacy & data control

## Advanced interaction themes
- Adaptive recommendations
- Explainable AI
- Context-aware scheduling
- Automation with user override
- Enhanced visual analytics
- What-if simulation
- Wellbeing-aware planning
- Collaborative workspace
- Accessibility controls
- Privacy and decision transparency

The final coursework submission should use the required 10 medium-fidelity mock-ups and explain the rationale for the chosen screens; this expanded set is a development/prototyping workspace.

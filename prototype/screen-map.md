# UniFlow Screen Map

| # | Screen | Primary interaction | UX purpose |
|---|---|---|---|
| 01 | Onboarding | Get started | Set expectations and reduce entry friction |
| 02 | University Sign-in | Authenticate | Secure, familiar entry |
| 03 | Personalisation | Select goals/availability | Establish user needs |
| 04 | AI Dashboard | Review recommendation | Make next action visible |
| 05 | Smart Calendar | Resolve conflicts | Support context-aware planning |
| 06 | Task Manager | Prioritise/complete | Efficient task handling |
| 07 | AI Planner | Generate plan | Reduce planning effort |
| 08 | Generated Plan | Edit/accept | Preserve user control |
| 09 | Focus Mode | Start/pause/end | Support focused activity |
| 10 | Wellbeing | Check in/adjust | Support reflective UX |
| 11 | Group Workspace | Coordinate | Support collaborative activities |
| 12 | Analytics | Explore patterns | Support reflection |
| 13 | What-if Simulator | Test scenario | Help users reason about trade-offs |
| 14 | Accessibility | Adjust interface | Support diverse users |
| 15 | Privacy & Data | Configure controls | Increase transparency and control |
